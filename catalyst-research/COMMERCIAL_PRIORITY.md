# 商机开发优先方案（064）
用户业务前提：已拥有国内领先、吨水成本具优势的成熟膜法方案（用户陈述，尚未给出适用边界、可比成本、案例或性能验证；不将优势强行套用每厂）。研究目标由学术全覆盖转为可对接、可初筛、可核价的销售技术情报，保持原始工程数据库不变。

## 全库覆盖和首批30个
v_commercial_market_overview 每个主体一行，按现场需求证据、身份、已知渠道及资料缺口排序，保留310全库，不把集团/研发/退役当在产工厂。v_commercial_priority_30 为30个互异主体手工初筛，有原水记录、原来源及具体业务假设，A优先取证/对接研究、B次级资格核实；不等于确认采购需求、已触达、合格商机或预期收入。新增数据后重新审查，不自动覆盖历史证据。投资者/环评公众参与或环保信息公开渠道只用于原用途；总机为转接，项目公告联系仅按公告用途。不得发信/拨打或代表用户报价，除非另获明确授权。
 
优先采集：①可处理的实际分股年量、峰值、时段、目前设施和原水波动；②汽提、MVR/多效、委外、膜浓缩的单位消耗与价格（蒸汽、电、药剂、清洗、膜耗、人工、废盐/浓水及外委），产品/副产物收益；③新增/替换时机、设计院、EPC、采购方、既有供应商、合同包/验收和保修；④公开采购、生产、技术、设备、EHS负责人工作渠道及厂区范围；⑤出水/回用指标、浓水可处置边界、现场空间、停车窗口；⑥集团复制机会及决策路径。当前公开私有成本缺口继续保留private_hold，但不得因此停止商机筛查；使用后续合规技术交流待填字段，不猜实际价格。
 
经济性按同一流股、同单位、相同时期和成本范围比较。annual_comparable_volume 不得取全厂设计能力乘365冒充实流；必须用实测或明确假设。吨和立方不自动互换。旧/新单位成本含相同项目，不重复计算收益；annual_incremental_net_recovery 为单位成本之外的增量净收益，已计入成本则填0；负收益可记录。年净节省=可比年处理量×(旧单位成本−新单位成本)+额外净回收收益；静态回收期=增量投资/正的年净节省。未知输入留空，不输出结果。商业情景表初始空，用户技术性能与成本未给定，不制造数字。设计与真实实测明确分层。
 
每轮30目标优先从A/B资格缺口、C交集与备用高价值目标选，区分新项目、正在采购、已中标、验收后优化、历史设施；已中标不称仍可参与原标。所有客户评分是销售研究假设而非确认意向；缺少关键数据不得宣称可实施。每轮报告高价值新工程事实、供应链/采购节点、有效业务渠道、成本输入与实际合格客户数量。以数据库实际查询为准。
 
复算：SELECT commercial_queue,count(*) FROM v_commercial_market_overview GROUP BY 1; SELECT priority_band,count(*),sum(public_channels>0),sum(role_channel_candidates>0) FROM v_commercial_priority_30 GROUP BY 1; SELECT * FROM v_commercial_priority_30 ORDER BY priority_band,site_id;
