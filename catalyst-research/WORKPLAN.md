# 中国催化剂工业废水调查施工规范 v0.2
目标：尽可能完整枚举中国大陆规模化催化剂实际制造基地（含自制、外资、再生，载体另列），优先完善逐厂水处理。吨位仅用于优先级，贵金属/新能源按工业化规模单独判断。
## 每个工作包
1. 从 GitHub 分支最新版本读取基线、历史迁移、待办和进度；不依赖对话记忆。用 build.py 重建；核对新增记录与旧 ID、企业更名、同址集团项目；保留历史。
2. 按产品、地区、监管名录、采购/标准和工程招标独立补漏；记录搜索词、实际来源、结果和失败；先核对万吨级、千吨级以及高价值小吨位工业厂，不能只增加名称。
3. 每厂依次核对法定主体/信用代码、厂址/园区、产品及生产线、产能口径/单位/年份、审批/验收/在产状态。集团及项目不得计入实际独立工厂合计。
4. 废水逐股调查：产生环节、污染物及浓度、年产生量、站进水和设备能力、分质预处理、核心生化/膜/蒸发、最终去向、污泥和盐处置、验收监测、运行费用、改造。无工艺废水、委外和回用分别标记，空值不等于零。
5. 证据优先：验收及运行记录、排污许可、环评报告/批复、企业披露、供应商案例、其他网页。逐条记录 URL、日期、页码/范围，区分设计/已建/运行/历史，冲突并存并解释；禁止从行业常规推断具体工厂采用工艺。
6. 模型知识可录为 MODEL_UNVERIFIED（未有网页数据证明），明确是模型知识线索而非可检索训练数据库原始记录；只写有把握的具体事实线索，不凭猜测补数；不与网页证实数据混算。推断另标 INFERRED，未知留空。历史摘要标 LEGACY_PENDING，不因存在旧引文升级。
7. 数据修改采用编号 SQL 迁移，保持基线 CSV 不变；事务、外键、唯一键检查；记录本轮搜索、字段增量、未决问题与下一工作包。每次提交数据库全量可重建内容及施工日志；不修改 main，不 force push。
## 工作包顺序
W00 基线导入及可重建验证；W01 优先大厂水处理：中触媒、迅凯、科林、齐茂、润和等；W02 FCC/分子筛各基地；W03 铜镍、合成气、基础化工；W04 聚合/胺/有机金属；W05 SCR/汽车；W06 贵金属/新能源/水处理催化剂；W07 HW50再生；W08 31省园区及监管反查；W09 采购和行业总产能闭合；W10 全库冲突复核。每个工作包可以拆为多批，不要求按固定轮数停止。
## 验收
每轮输出主体记录数（非已核实工厂数）、分级证据数、具体工艺覆盖/水量覆盖、仍缺失数、独立路径新增厂商；按细分行业核对同口径总产能。未发现不是不存在；找不到网页不等于事实不存在。仅在重要遗漏趋于收敛且独立来源已充分检查时报告接近覆盖，不能宣称全量。
