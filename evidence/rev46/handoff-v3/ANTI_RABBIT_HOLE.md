# Anti-rabbit-hole execution rules

## Three mandatory scales
1. **NOW — exact next:** one authorized action only.
2. **NEXT HORIZON:** next 2–4 decision nodes with pass/fail exits.
3. **NORTH STAR:** host numerical gate -> host structural qualification -> target-device truth -> production integration, with preserved learned/student contingency.

A handoff is incomplete if the agent knows only NOW.
